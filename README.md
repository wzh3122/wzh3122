## wzh3122

做面向真实场景的 AI 工具。关注复杂文档中的信息如何被找到、理解和使用，也关注视觉数据从标注到交付的工作流程。

### 项目

**[ATRAG](https://github.com/wzh3122/ATRAG)** — 复杂文档知识库与问答工作台。涵盖文档解析、索引构建、混合检索、Agent 问答和容器化部署。

**[RoadLabel Studio](https://github.com/wzh3122/RoadLabel-Studio)** — 道路检测图像标注桌面工具。支持分类分级、矩形框检测、人工审核及 YOLO / VOC 导出。

主要使用 Python。项目的设计、功能与运行方式详见各仓库。
